### Reproducción aislada de R01

Se evaluó el código real de slot.ts con TypeScript, retirando únicamente el import server-only para poder cargarlo en Node. No se cambió el algoritmo. Reloj simulado, sin esperar diez minutos:

1. En t=1000, A reserva: true.
2. En t=601001, A continúa activo y B reserva: true.
3. Se ejecuta la liberación tardía de A: hayExportacionEnCurso devuelve false aunque B continúa.
4. C reserva: true mientras B sigue activo.

La caducidad de una marca no cancela una promesa, una descarga o una composición. El fallo es de exclusión/propiedad de la reserva; el consumo excesivo es un riesgo derivado, no un OOM observado. No existe una regresión dedicada a slot.ts en la suite actual. La reserva sí protege correctamente el caso normal anterior a su caducidad: no se debe describir como ausente.
